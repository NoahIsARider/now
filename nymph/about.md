Nymph is the blog of noahisarider. It is built by hand — plain markdown
files, a small Python build, no tracking and no comments platform.

## What gets written here

- Notes from reading, when a paper or a book needs arguing with.
- Notes from watching and listening, when a list entry is not enough.
- Build logs from small software projects, including this site itself.
- Anything that wants prose instead of a rating.

## How the site is made

Every post is a markdown file with a few lines of metadata at the top.
Adding one means dropping a file into a folder and rebuilding; there is no
database and no admin panel. The type is Fraunces, the interface type is
Inter, and both are self-hosted. The lemon wall is the only decoration.

An RSS feed lives at [feed.xml](feed.xml), and everything else I keep is
linked from the footer.
